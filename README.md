# 视觉回归基线审批与差异定位平台

基于 Vue 3 的本地可运行前端工程，用于管理截图回归运行、差异定位、忽略规则和基线审批。数据由 Axios 模拟适配器提供，并持久化到浏览器 `localStorage`。

## 技术栈

- Vue 3 + TypeScript + Vite
- Arco Design Vue
- Pinia
- Vue Router
- TanStack Query for Vue
- Axios

## 启动

```bash
npm install
npm run dev
```

默认开发地址为 `http://localhost:18471`。

## 构建

```bash
npm run build
npm run preview
```

## 逻辑验证

```bash
npm run test:e2e
```

脚本在 Node 中用 esbuild 打包 mock API 并驱动完整工作流（54 项断言）：依据冻结、
单页隔离、规则/截图失效与复议、跨窗口写锁与草稿、同修订原子生效、写入失败后的
检查点恢复与幂等重放。

## 批准批次：同一条批准依据

「批准批次」把回归运行、差异区域、忽略规则和新基线接成一条可审计依据链：

1. **建批次冻结依据**：每个页面记录当前图指纹（FNV-1a）、命中规则的内容快照与
   规则集指纹、全局规则修订号、差异区域快照。
2. **单页结论隔离**：逐页批准/驳回只写对应页面与对应运行；批次生效前不切换任何
   基线，结论留痕所依据的图指纹与规则修订。
3. **即时失效**：忽略规则增删改/启停（全局修订号前移）或当前图被重新采集后，
   命中的页面立即变为「依据失效」回到待审，原依据与原结论归档进**复议项**；
   与变化无关的页面不失效，依据自动对齐到新修订并记录对齐日志。
4. **统一生效**：只有全部页面给出结论、无失效页、且每页依据都对齐到同一规则修订
   时，批次才一次性停用旧基线、写入同修订新基线（幂等确定性 ID）。
5. **单窗口写入**：批次写锁带 5 秒心跳与 15 秒 TTL；其他窗口只能保存草稿，草稿
   自动标出建批次后已变化的页面。新开浏览器标签页会得到不同窗口身份，可直接演示。
6. **检查点恢复**：每页审批即写检查点；生效阶段逐页落盘，写入失败后批次回到开放
   状态，已落库页面不重复新增审批或基线，重试时以「基线是否真实存在」为幂等判据
   继续未完成页面。批次详情页提供「注入写入失败（演练）」按钮模拟崩溃。

## 工作区

- 运行概览：发布阻断项、差异趋势和最近运行
- 回归运行：按项目、页面、设备、主题、构建和状态筛选，合并重复运行
- **批准批次**：冻结依据、逐页结论、失效复议、写锁草稿、原子生效与恢复
- 差异定位：基线/当前图并排、区域缩放、严重级筛选、区域忽略和审批
- 审批队列：开放批次入口、批量合并、风险排序和审批入口
- 历史基线：版本、批准人、原因、关联运行、批次来源、生效修订和启用状态
- 忽略规则：动态区域选择器、作用范围、最大色差、规则修订号和启用控制
- 结果导出：导出包含运行、差异和审批证据的 CSV

浏览器首次打开时会自动写入示例数据。审批、批次或规则调整会写入 `visual-regression-platform-v1` 对应的本地存储键；旧版本地数据会自动迁移补全批次表与规则修订号。
